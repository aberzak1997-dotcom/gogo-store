# WIVITEC — Technology. Elevated.
E-commerce store for WIVITEC, Morocco's premier tech destination.

## Stack
- React + Vite
- Supabase (database)
- CJ Dropshipping (product supplier)
- Tailwind CSS

## Getting Started
1. Clone the repo
2. Run `npm install`
3. Add `.env` file with Supabase + CJ API keys
4. Run `npm run dev`
